# Hi, I'm Aishvi 👋

I'm a student exploring data science and machine learning by actually building things, not just following tutorials. I like taking something I just learned (a model, a library, a technique) and turning it into a small end-to-end project I can poke at and break.

Right now I'm mostly interested in applied ML on real-world signals/data (health data, documents, text) and in how LLM-based agents are built, not just prompted.

## Some projects I've built

- **[sleep-apnea-ecg-detection](https://github.com/aishvihere/sleep-apnea-ecg-detection)** — Detects sleep apnea minute-by-minute from a single ECG lead. Full pipeline: signal filtering, 22 hand-crafted features (HRV, frequency-domain, nonlinear), XGBoost evaluated with leave-one-subject-out CV, explained with SHAP. ROC-AUC 0.76 — written up honestly, limitations included.
- **[ai-video-assistant](https://github.com/aishvihere/ai-video-assistant)** — Turns a YouTube video or audio file into a summary, action items, decisions, and a chat you can ask follow-up questions to (RAG over the transcript).
- **[langgraph-agentic-ai](https://github.com/aishvihere/langgraph-agentic-ai)** — Working through how LangGraph handles state, memory, and branching logic for agentic workflows, with a small chatbot as the playground.
- **[Bank-management-Project](https://github.com/aishvihere/Bank-management-Project)** — A banking operations REST API (FastAPI) with account creation, auth, deposits/withdrawals, and validation rules — practicing OOP and clean API design.
- **[Student-Salary-Prediction](https://github.com/aishvihere/Student-Salary-Prediction)** — Gradient boosting model predicting salary from student profile data.
- **[Working-with-pipelines](https://github.com/aishvihere/Working-with-pipelines)** — scikit-learn pipelines + transformers on the Titanic dataset, with a serialized model to mimic production-style inference.
